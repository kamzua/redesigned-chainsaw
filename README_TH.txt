วิธีสร้างไฟล์ EXE บน Windows

ข้อสำคัญ: สภาพแวดล้อมที่สร้างไฟล์ชุดนี้ไม่ใช่ Windows จึงยังไม่ได้คอมไพล์
ไฟล์ .exe ให้โดยตรง ชุดนี้มีสคริปต์สำหรับสร้าง EXE บน Windows จริง

1. ติดตั้ง Python 3.11 หรือ 3.12 จาก https://www.python.org/downloads/windows/
   ระหว่างติดตั้งให้เลือก Add Python to PATH
2. แตกไฟล์ ZIP นี้ไว้ในโฟลเดอร์หนึ่ง
3. ดับเบิลคลิก build_windows.bat แล้วรอจนเสร็จ
4. ไฟล์จะอยู่ที่ dist\AuditionSweetDreams.exe

ข้อกำหนด:
- เครื่องที่ใช้รันต้องมี Google Chrome ติดตั้งอยู่ เพราะโปรแกรมใช้ Selenium
- ตอน build ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อติดตั้งแพ็กเกจ
- ตอนใช้งาน Selenium อาจต้องใช้อินเทอร์เน็ตเพื่อจัดหา ChromeDriver/เปิดเว็บ
- เก็บไฟล์ EXE ในโฟลเดอร์ที่มีสิทธิ์เขียน เพื่อให้ไฟล์ตั้งค่าและประวัติถูกบันทึกได้
- ทดลองกับบัญชีทดสอบก่อนใช้งานจริง และอย่าแชร์ไฟล์ตั้งค่าที่มีข้อมูลบัญชี

หาก Windows Defender เตือน ให้ตรวจสอบไฟล์และแหล่งที่มาก่อนอนุญาตให้ทำงาน
